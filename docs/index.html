## Temperature Web Interface A browser-based interface is available for reading temperature data directly from the ESP32. The interface displays the current temperature and plots the temperature signal over time. ### Open the interface [Open VO2 Max Mask Temperature Monitor](https://shouroukjommaa94.github.io/VO2max---MASK/) ### How to use 1. Open the web interface using Google Chrome or Microsoft Edge. 5. Click **Connect ESP32**. 6. Select the ESP32 USB serial port. 7. Temperature measurements will be displayed and plotted over time. The temperature signal can later be used to identify breathing cycles and calculate respiratory frequency.
